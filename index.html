What is happening?

The wave function ψ(x,t) describes the quantum state of the particle. It is a complex-valued function of position and time, so at every point we track both a real and an imaginary component.

Its probability density is |ψ(x,t)|² — this tells us how likely the particle is to be found near position x at time t. Integrated over all space it must always equal 1, since the particle exists somewhere.

The Schrödinger equation determines exactly how the wave function evolves in time, given the system's potential energy V(x). QuantumVision solves this equation numerically using a split-step Fourier method, which alternates between position space (where the potential acts) and momentum space (where kinetic energy acts).

The ML model attempts to learn this evolution directly from previously generated physical trajectories — given ψ at one instant, it predicts ψ a short time later. Run autoregressively, its own predictions become its next inputs, so small errors can compound over time. This application compares the ML approximation with the numerical physics solution, frame by frame, so those errors are visible rather than hidden.

The model learns a numerical approximation to the wave-function dynamics for this specific simulated system — it has not learned quantum mechanics in general, and this is not a quantum computer, a universal quantum simulator, or an exact quantum predictor.
